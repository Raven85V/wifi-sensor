# Wi-Fi датчик для PixelHub 75 (ESP8266 / ESP32)

Простая прошивка датчика: читает температуру/влажность/давление и раз в N секунд отправляет их на матрицу PixelHub:

```
http://<IP матрицы>/api/sensor?id=<имя>&t=..&h=..&p=..
```

## Поддерживаемые датчики

| Датчик | Что даёт | Шина |
|---|---|---|
| BME280 | температура, влажность, давление | I2C |
| BMP280 | температура, давление | I2C |
| DS18B20 | температура | 1-Wire |

Датчик определяется автоматически при старте (BME280 → BMP280 → DS18B20).

## Сборки

```bash
pio run -e esp8266              # NodeMCU / Wemos D1 mini
pio run -e esp8266 -t upload

pio run -e esp32                # ESP32 DevKit
pio run -e esp32 -t upload
```

## Пины

### ESP8266 (NodeMCU / Wemos D1 mini)

| Сигнал | Пин |
|---|---|
| I2C SDA | D2 (GPIO 4) |
| I2C SCL | D1 (GPIO 5) |
| DS18B20 DATA | D5 (GPIO 14) |
| Светодиод | D4 (GPIO 2, встроенный, активный LOW) |

### ESP32

| Сигнал | Пин |
|---|---|
| I2C SDA | GPIO 21 |
| I2C SCL | GPIO 22 |
| DS18B20 DATA | GPIO 4 |
| Светодиод | GPIO 2 |

Питание датчиков — **3,3 В**. Для DS18B20 резистор 4,7 кОм между DATA и 3,3 В.

## Настройка

1. Прошить плату.
2. При первом включении поднимается точка доступа **Sensor-Setup** (без пароля).
3. Подключиться и открыть `http://192.168.4.1`.
4. Указать:
   - Wi-Fi сеть (только 2,4 ГГц) и пароль;
   - IP матрицы (например `192.168.1.172`);
   - имя датчика (`id`) — должно совпадать с именем слота на странице `/settings/sensors` матрицы;
   - интервал отправки (10…3600 с).
5. Сохранить — плата перезагрузится и начнёт отправку.

Если сеть не найдена, плата снова поднимает точку доступа для настройки.

## Проверка

- на матрице: `/settings/sensors` — значение появится в слоте с тем же `id` или в блоке «Обнаружены новые датчики»;
- вручную: `http://<IP матрицы>/api/sensor?id=test&t=21.5&h=45&p=1013`.

## Светодиод

| Режим | Поведение |
|---|---|
| подключение к Wi-Fi | частое мигание |
| штатная работа | короткая вспышка после отправки |
| режим настройки (AP) | не мигает |
